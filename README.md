# PrepSaathi AI

PrepSaathi AI is an AI-powered placement preparation platform designed to help students prepare for interviews, DSA, aptitude, and technical subjects using personalized AI workflows.

## Features
- AI Interview Assistant
- Resume Analyzer
- Personalized DSA Roadmaps
- Mock Interviews
- AI Quiz Generator
- Progress Tracking

## Tech Stack
- Next.js
- TypeScript
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
